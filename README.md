# Телеграм-бот для записи на занятия

Бот на Aiogram 3 с интеграцией Google Calendar для бронирования уроков у репетитора.

## Возможности
- /start — приветствие и выбор направления.
- Выбор свободного времени по данным Google Calendar.
- Подтверждение и создание события в календаре.
- Напоминания за 24 часа и за 1 час (APScheduler).
- /my_lessons — список записей и отмена с удалением события.

## Запуск
1. Создайте файл `.env` по примеру `.env.example` (бот-токен, `GOOGLE_CALENDAR_ID`, путь к `service_account.json`).
2. Установите зависимости: `pip install -r requirements.txt`.
3. Запустите: `python -m bot.main`.

SQLite база создаётся автоматически при старте.
